# Evaluation Outputs

This directory is reserved for external evaluation outputs; it currently contains no judgments or scores.

Use a separate subdirectory for each batch. Retain original judge responses, parse/error histories, selected-record provenance, task-level final outcomes, and the final summary. Document the denominator and the judgment-selection and aggregation rules.

Identify the exact frozen task commit and execution-artifact inputs. Evaluation scripts belong in [`../evaluator/`](../evaluator/), and execution-evidence links are in the [repository README](../README.md#published-materials).
