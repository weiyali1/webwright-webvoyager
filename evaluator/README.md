# Evaluation Scripts

This directory is reserved for the scripts and public configuration actually used for external evaluation; no evaluation script has been added yet.

When evaluation is prepared, publish the script version, prompt source, judge configuration, input-selection policy, and parsing/aggregation behavior. Keep credentials and private service connection values out of public configuration.

Task definitions are in [`../benchmark/`](../benchmark/). Evaluation outputs belong in [`../evaluation/`](../evaluation/).
